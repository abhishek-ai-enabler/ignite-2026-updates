        The big picture

        How they fit together

        Copilot Studio builds the agents, Microsoft IQ grounds them in organizational context, Microsoft Foundry runs and continuously improves them, Agent 365 governs, secures and measures them, and Power Platform supplies the low-code apps, flows and data they build with and act on.

        1. Build with Copilot Studio

          Makers and developers create agents, workflows and apps for business processes.

        2. Ground with Microsoft IQ

          Work, data, web and knowledge context so agents act on what your organization knows.

        3. Run with Microsoft Foundry

          Models, Agent Service and continuous improvement to run agents at scale and keep making them better.

        4. Connect with Power Platform

          Apps, flows and Dataverse data become tools and context for agents, within existing permissions.

        5. Govern with Agent 365

          Registry, identity, risk controls and cost and value measurement for every agent.
